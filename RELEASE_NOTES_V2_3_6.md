# Rx Offline V2.3.6 — UI/Recipe Polish

## Included changes
- The printed prescription logo no longer prints the theme name inside the logo.
- Added 3 elegant logo presets in Settings → **Logo clínico**:
  - Monograma clínico
  - Escudo elegante
  - Minimal serif
- Added **Fecha de nacimiento** visibility improvements and **automatic age calculation**.
- Patient sex is now normalized and displayed as **F / M / O**.
- The patient section on the prescription now stands out more with a clearer premium card layout.
- The selected patient summary in the prescription form is more prominent and easier to read.
- Added inline age hint in the patient form: **Edad calculada automáticamente**.
- Pediatric weight visibility remains automatic for minors.
- QR behavior preserved as working correctly.

## Main files changed
- `app.js`
- `index.html`
- `styles.css`
